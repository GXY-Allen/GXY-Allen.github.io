# 自定义外观：背景、主题色和看板娘

这个博客的外观有**两层**设置。

## 第一层：站点默认值（改代码）

所有默认值都在 `src/site.config.ts` 里，改完发布后所有访客都会看到：

```ts
appearance: {
  mode: 'auto',          // 'auto' 跟随系统 / 'light' / 'dark'
  primary: '#5b8def',    // 主题色
  background: 'photo',   // 默认背景，对应下面 backgrounds 里的 id
  backgroundBlur: 0,     // 背景模糊
  cardOpacity: 0.78,     // 卡片不透明度
  fontSize: 17,          // 正文字号
},
```

### 换背景图

1. 把图片放到 `public/images/` 下，比如 `public/images/my-bg.jpg`
2. 在 `backgrounds` 里加一项，并把 `background` 改成它的 id：

```ts
backgrounds: [
  { id: 'mine', name: '我的背景', type: 'image', value: '/images/my-bg.jpg' },
  // 也可以是渐变或纯色：
  { id: 'pink', name: '粉色', type: 'gradient', value: 'linear-gradient(135deg, #fbc2eb, #a6c1ee)' },
  { id: 'gray', name: '灰色', type: 'color', value: '#eeeeee' },
],
```

> 背景图建议宽度 1920～2560 像素、大小 500KB 以内，加载更快。

### 其他常改的地方

| 想改的 | 位置 |
| --- | --- |
| 标题、副标题、简介 | `title` / `subtitle` / `author.bio` |
| 头像 | 图片放 `public/images/`，改 `author.avatar` |
| 首页横幅图 | `banner` |
| 打字机标语 | `slogans` |
| 公告 | `notice` |
| 顶部导航 | `nav` |
| 社交链接 | `social` |
| 每页文章数 | `pageSize` |
| 看板娘 / 访问统计 / 热力图开关 | `features` |
| 「关于」页面内容 | `src/content/pages/about.md` |

## 第二层：访客自己调（设置面板）

点右上角的 🎨 按钮打开设置面板，可以调：

- 浅色 / 深色 / 跟随系统
- 主题色（预设色板，或者用取色器任选）
- 背景（预设、本地图片、图片链接）
- 背景模糊、卡片透明度、正文字号
- 开关动画特效、看板娘

这些设置**只保存在访客自己的浏览器里**，不会影响别人。

## 看板娘

看板娘只在宽度 1024 像素以上的电脑上加载，手机上不会出现，不影响阅读。

- 台词在 `public/live2d/waifu-tips.json` 里，可以随便改
- 想默认关闭：`features.live2d.enable` 改成 `false`
- 访客可以点看板娘旁边的 × 关掉，或者在设置面板里关
