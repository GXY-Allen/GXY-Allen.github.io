# 写作与发布

这篇文章介绍这个博客**最核心的用法**：怎么新建文章、怎么放图片、怎么发布。

## 一句话版本

> 把 `.md` 文件和图片放进 `src/content/posts/` 下的某个文件夹，双击根目录的 `发布.bat`，一两分钟后网站就更新了。

## 文章放在哪里

所有文章都在 `src/content/posts/` 目录下，**文件夹就是分类**：

![目录结构](./images/folders.png)

```text
src/content/posts/
├── 技术/                     ← 分类「技术」
│   ├── _category.yml         ← 分类设置（可选：图标、简介、排序）
│   ├── Git指南.md            ← 单文件文章（图片用外链）
│   └── 前端/                 ← 子分类「技术 / 前端」
│       └── CSS 笔记.md
├── 随笔/
│   └── 第一次露营/           ← 带本地图片的文章：一篇文章一个文件夹
│       ├── index.md
│       ├── 帐篷.jpg
│       └── images/星空.png
└── 随手记.md                 ← 根目录下的文章归入「未分类」
```

两种组织方式都可以：

| 方式 | 适合 | 图片写法 |
| --- | --- | --- |
| `分类/文章名.md` | 纯文字或用图床的文章 | 外链，或放在同目录 |
| `分类/文章名/index.md` | 有很多本地图片的文章 | `![](./图片.png)` |

## 开头的信息（全部可选）

文章开头可以写一段 `---` 包起来的信息（叫 frontmatter），**一个都不写也能发布**：

```yaml
---
title: 文章标题          # 不写就用正文第一个「# 标题」，再没有就用文件名
date: 2026-10-17 20:30  # 不写就用第一次提交到 git 的时间
tags: [Git, 工具]        # 标签，也可以写成 tags: Git, 工具
category: 技术/前端      # 不写就用所在文件夹
description: 一句话摘要  # 不写就自动截取正文开头
cover: ./cover.png      # 封面，不写就用文章里第一张图
series: 专栏名           # 加入某个专栏
seriesOrder: 1          # 在专栏里的顺序
pinned: true            # 在首页置顶
draft: true             # 草稿：本地预览能看到，发布后不显示
---
```

## 三个常用操作

### 1. 本地预览

双击根目录的 **`预览.bat`**（或者在终端运行 `npm run dev`），浏览器打开 <http://localhost:4321>。之后每次保存 md 文件，页面会**自动刷新**。

### 2. 新建文章

```bash
npm run new "文章标题" 分类名
# 例如：npm run new "CSS 笔记" 技术/前端
```

会自动生成 `src/content/posts/技术/前端/CSS 笔记/index.md`，并带好 frontmatter 模板和 `images` 文件夹。

### 3. 一键发布

双击 **`发布.bat`**（或 `npm run publish`），它会：

1. 先在本地构建一遍，确保没有错误（有错会停下来并告诉你）
2. 自动写好提交说明，比如「新增文章：CSS 笔记」
3. 推送到 GitHub

推送之后，GitHub Actions 会自动构建并部署，一两分钟后刷新网站就能看到。

> [!TIP]
> 也可以不用脚本：自己 `git add`、`git commit`、`git push` 效果一样。

## 图片怎么放

推荐「一篇文章一个文件夹」，图片和 `index.md` 放在一起，然后用相对路径引用。各种常见写法都支持，详见专栏下一篇 [Markdown 写作示例](/posts/博客指南/Markdown示例/)。

本地图片在构建时会被**自动压缩成 WebP**，所以直接放手机拍的大图也没关系。

## 用 Typora 写作

Typora 里打开 `偏好设置 → 图像`，设置为：

- 插入图片时：**复制图片到 `./${filename}.assets` 文件夹**
- 勾选「优先使用相对路径」

之后直接粘贴截图，图片会自动存到文章旁边，发布时一起上传。
