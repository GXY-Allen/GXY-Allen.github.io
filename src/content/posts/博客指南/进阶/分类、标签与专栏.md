# 分类、标签与专栏

这篇文章本身就放在 `博客指南/进阶/` 文件夹里，所以它的分类是「博客指南 / 进阶」——这就是**多级分类**。

## 分类：文件夹即分类

- 新建一个文件夹 = 新建一个分类，不用改任何配置
- 文件夹可以嵌套，形成子分类，左侧栏的分类树会自动显示层级和文章数
- 父分类页面会同时显示所有子分类里的文章
- 不想按文件夹？在 frontmatter 里写 `category: 技术/前端` 可以覆盖

### 给分类加图标和简介

在分类文件夹里放一个 `_category.yml`（可选）：

```yaml
name: 技术            # 显示名（默认是文件夹名）
icon: 💻              # 图标，可以用任意 emoji
description: 编程与工具笔记
order: 1              # 排序，越小越靠前（默认按文章数）
cover: ./cover.jpg    # 分类页横幅图（相对这个 yml 文件）
```

## 标签：横向的分类

一篇文章只属于一个分类，但可以有多个标签：

```yaml
tags: [Git, 工具, 入门]
```

所有标签会汇总在「标签」页，点进去能看到同标签的文章。

## 专栏：把文章串成系列

适合教程、读书笔记这类有先后顺序的内容：

```yaml
series: 博客使用指南
seriesOrder: 4
```

同一个 `series` 的文章会组成一个专栏：

- 文章顶部会显示专栏目录和阅读进度
- 「专栏」页面列出所有专栏
- 不写 `seriesOrder` 就按发布时间排序

## 置顶和草稿

```yaml
pinned: true   # 首页置顶
draft: true    # 草稿，只在本地预览时显示
```
